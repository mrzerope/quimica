# Guía de Estudio — Química General y Orgánica

Página web estática lista para GitHub Pages.

## Archivos
- `index.html` — contenido de la guía.
- `style.css` — diseño responsive.
- `script.js` — buscador, modo oscuro, progreso y quiz.

## Publicarla en GitHub Pages

1. En GitHub crea un repositorio, por ejemplo: `guia-quimica`.
2. Sube `index.html`, `style.css` y `script.js` a la raíz del repositorio.
3. Entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`.
6. Guarda los cambios.
7. GitHub generará una dirección parecida a:
   `https://TU-USUARIO.github.io/guia-quimica/`

## Contenido
La guía está organizada a partir de los materiales de clase proporcionados:
- Sesión 7: funciones químicas inorgánicas y nomenclatura.
- Sesión 9: estructura molecular y reacciones químicas.
- Sesión 10: enlace químico.
- Sesión 11: energía, energía de activación, catalizadores y estequiometría.
- Sesión 12: soluciones y concentración.
- Sesión 13: soluciones, coloides, suspensiones y agua.
- Sesión 15: ácidos y bases, Arrhenius y Brønsted–Lowry.
- Práctica integradora PC 02: preguntas y ejercicios de repaso.

No se requieren instalaciones ni librerías externas.
